# Project instructions

- Before each project build, increment the patch component of `mod_version` in `gradle.properties` by one. Keep the `-alpha` suffix on every version until the project owner explicitly decides to move to beta. For example, `1.0.0-alpha` becomes `1.0.1-alpha`.
- The root `assets/` directory is for source assets supplied by the project owner. Incorporate files into the appropriate Minecraft resource locations when implementing features.

- Name classes after what they do, and keep code clean and maintainable.
